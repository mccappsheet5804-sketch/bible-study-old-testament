# 創世記 1:1–2:25 完整分析報告

本文件採用四種方法分析經文：結構分段、神學主題、對比分析、事件分析表。

**經文範圍**：創世記 1:1 – 2:25（和合本修訂版）

---

## 方法一：結構分段分析

| 段落 | 主題 | 經節 |
| --- | --- | --- |
| 1 | 七日創造總綱（神／以羅希姆） | 1:1–2:3 |
| 2 | 天地與人類受造的更細描述（耶和華神） | 2:4–9 |
| 3 | 伊甸園的四條河與環境 | 2:10–14 |
| 4 | 人的職責與禁令 | 2:15–17 |
| 5 | 造動物與為人造配偶 | 2:18–25 |

**分析結論**：經文由兩個創造敘事組成，第一個強調秩序與安息（1:1–2:3），第二個聚焦於人、土地與關係（2:4–25）。分段點在 2:4「這就是天地創造的來歷」。

---

## 方法二：神學主題分析

1. **神的安息與分別為聖**  
   - 經節：1:26–31 → 2:1–3  
   - 重點：神完成創造後安息，並賜福第七日，將其分別為聖。

2. **人的來源與本質**  
   - 經節：2:7  
   - 重點：塵土 + 生命之氣 = 有靈的活人。人兼具物質與神聖氣息。

3. **伊甸園的象徵**  
   - 經節：2:9–14  
   - 重點：生命樹（永生）、知善惡的樹（道德界限）、四條河流、金子與寶石（豐盛與榮美）。

4. **工作與責任**  
   - 經節：2:15, 19–20  
   - 重點：耕耘、看管、命名動物。人在受造界中扮演管理與文化的角色。

5. **婚姻的設立**  
   - 經節：2:23–24  
   - 重點：妻子從男人肋骨所造，二人成為一體。婚姻是「離開—結合—一體」的盟約關係。

6. **禁令與自由**  
   - 經節：2:16–17  
   - 重點：園中所有樹可隨意吃，唯獨知善惡的樹不可吃。自由中包含順服的界線。

## 方法三：對比分析（創1:1–2:3 vs 創2:4–25）

| 比較項目 | 創世記 1:1–2:3 | 創世記 2:4–25 |
| --- | --- | --- |
| 稱呼神 | 神（Elohim） | 耶和華神（YHWH Elohim） |
| 創造順序 | 光 → 天空 → 旱地 → 植物 → 光體 → 魚鳥 → 動物 → 人（男與女同時） | 人 → 植物 → 動物 → 女人 |
| 造人方式 | 「我們要照著我們的形象造人」（1:26） | 塵土造人，吹生命之氣（2:7） |
| 造女人方式 | 同時造男造女（1:27） | 用男人的肋骨建造（2:22） |
| 焦點 | 宇宙秩序、時間節奏（七日） | 土地、園子、關係、倫理 |
| 關鍵動詞 | 說、造、賜福 | 造、吹、安置、吩咐、取、建 |
| 人的職責 | 管理全地、生養眾多（1:28） | 耕耘看管伊甸園、命名動物（2:15, 19–20） |
| 倫理命令 | 未提及分別善惡樹 | 不可吃知善惡樹的果子（2:17） |
| 水源描述 | 未提及 | 四條河流詳細描述（2:10–14） |

**分析結論**：第一章呈現宏觀、神聖秩序與普世視角；第二章呈現微觀、關係與具體場景。二者互補，不矛盾。
