## 2. 問題與應答法（適合討論或反思）

### 引誘階段（1–6）
- **蛇如何扭曲神的話？**  
  把「不可吃」擴大為「不可吃任何樹上的嗎？」，又直接否定「必定死」。
- **女人在哪幾方面被試探？**  
  好作食物（肉體情慾）、悅人眼目（眼目情慾）、能使人有智慧（今生的驕傲）。

### 罪後反應（7–13）
- **他們第一時間做了哪兩件事？**  
  編織裙子遮蓋身體、躲藏避免見神。
- **男人與女人分別如何回應神的責問？**  
  男人推給女人（及神：「你所賜給我的女人」）；女人推給蛇。

### 審判與應許（14–19）
- **神咒詛蛇與咒詛人／地有何不同？**  
  蛇直接被咒詛本質；人與地則是因人的緣故受咒詛或受苦，但仍存憐憫。
- **第15節為何被稱為「原始福音」？**  
  第一次出現「女人的後裔」要傷蛇的頭，預告最終的拯救。

### 最後的隔離（20–24）
- **皮衣與無花果樹裙子的對比意義？**  
  人的自救（葉子）無法持久；神預備皮衣需要犧牲生命，象徵恩典與遮蓋。
- **為何不讓他們繼續吃生命樹果子？**  
  免得人在有罪與必死的狀態下永遠活著，那是另一種悲劇。

## 3. 主題式歸納（神學與講章預備）

1. **神的話語與懷疑**  
   蛇從「神豈是真說？」到「你們不一定死」，逐步瓦解信任。

2. **罪的連鎖效應**  
   看 → 貪 → 取 → 吃 → 給 → 掩蓋 → 懼怕 → 躲藏 → 推罪。

3. **公義與恩典的結合**  
   審判中的咒詛（14–19）與預備皮衣（21）在同一章中並存。

4. **關係的破裂**  
   人與神（躲藏）、人與人（推責）、人與自然（荊棘、勞苦）。

5. **救贖的伏筆**  
   女人的後裔（最後指向耶穌基督）要傷蛇的頭。

## 5. 關鍵詞/短語串聯（快速複習）

- **「神豈是真說…」** → 懷疑的種子  
- **「摘下來吃了」** → 行動  
- **「我在園中聽見…害怕…藏了」** → 罪後的懼怕與疏離  
- **「你所賜給我、與我一起的女人」** → 卸責  
- **「你要傷他的腳跟／他要傷你的頭」** → 已定勝局  
- **「皮子作的衣服」** → 需要流血的替代  
- **「基路伯…火焰劍」** → 聖潔的阻隔
