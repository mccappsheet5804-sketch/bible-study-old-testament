### Option 1 (Recommended)
```
# 要求
為 `https://bible.com/bible/139/gen.1.1-31.RCUV` 做一個「綜合研經整理報告」。
## 流程
1. 建議整理的方法
2. 用每一個建議的方法去整理
3. 加強與經文對比，再整理。
4. 用 Mermaid 優化每一個建議的整理方法
- 以「：」代替「:」 
5. 用「嚴謹經文對比版」，不肯定用「（不詳）」表示。
6. 將整理好的結果，有序地輸出為 README.md
7. 書寫用繁體中文
8. 必須要乎合基督教福音派立場
```
### Option 2
```
# 要求
## 目的
整理本章經文，並將整理好的最終結果，有序地輸出為 `README.md`。
## 聖經經文
`https://bible.com/bible/139/gen.1.1-31.RCUV`
## 必要條件
- 關於「內容」
  - 乎合基督教福音派立場
  - 嚴謹分析經文，不肯定就以「(n.a.)」表示
  - 重要：`時間`,`地點`,`角色`,`事件`
- 關於「展示格式」
  - 以繁體中文書寫
  - 如能提高效率，用圖表示（使用 `Mermaid`）
    - 可善用「：」
    - 注重內容的關係，不要混亂關係符號，特別要避免具誤導性的
### 流程
1. 建議分析與整理經文的方法
2. 根據建議的方法，分析與整理經文
3. 輸出`README.md`
```
